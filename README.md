# Đầu Tư Tương Lai — WordPress

Theme WordPress riêng cho https://daututuonglai.vn.

Chỉ quản lý mã nguồn giao diện. Không lưu wp-config.php, mật khẩu, cơ sở dữ liệu hoặc uploads trong repository.

Mã theme: `wp-content/themes/daututuonglai/`.

Cài đặt: sao lưu theme hiện tại; tải gói theme trong GitHub Actions; vào Giao diện → Themes → Thêm mới → Tải giao diện lên; kích hoạt Đầu Tư Tương Lai. Không cài lại WordPress hoặc nhập/xóa cơ sở dữ liệu.

Chưa cấu hình đồng bộ tự động vào hosting. GitHub là nguồn mã và tạo gói cài đặt.
